If the demo is down

The demo runs on a single free-tier machine (Oracle Cloud Always Free, one k3s node). It has no standby, so a restart, an upgrade or the provider reclaiming the machine takes it offline until it is brought back. While it is down, the API and ingestion refuse requests; the code and its test results stay available on GitHub.
